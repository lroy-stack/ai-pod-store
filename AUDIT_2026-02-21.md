# 1. RESUMEN EJECUTIVO

Plataforma e-commerce Print-on-Demand **100% gestionada por IA**. Un sistema de 9 agentes autonomos (PodClaw) investiga tendencias, genera disenos, crea productos, gestiona precios, atiende clientes, y reconcilia finanzas — todo sin intervencion humana.

## 4.3 Sistema de Hooks (Seguridad)

**PreToolUse (FAIL-CLOSED — bloquea si falla):**
1. `security_hook` — Bloquea tablas protegidas, limita cambios precio ±20%, escala refunds >100 EUR
2. `cost_guard_hook` — Budget diario por agente, estima costes por tool
3. `rate_limit_hook` — Limites por sesion y diarios

**PostToolUse (FAIL-OPEN — observacion):**
1. `event_log_hook` — Log en Supabase
2. `memory_hook` — Actualiza logs diarios y context files
3. `transparency_hook` — Moderacion automatica disenos
4. `sync_hook` — Sync variantes Printify → Supabase
5. `quality_gate_hook` — Flag quality < 7

## 4.6 Evaluacion Backend

### Fortalezas
- Seguridad fail-closed (exception bloquea tool)
- Budget enforcement dual (SDK + hook custom)
- Session persistence (resume via SDK)
- Logging event-sourced completo

1. **Un branch por worktree** — Git no permite checkout del mismo branch en dos worktrees
2. **No solapar archivos** — Cada agente trabaja en su area (frontend vs backend vs infra)
3. **npm ci por worktree** — Cada uno necesita su propio node_modules (~800 MB)
4. **Copiar .env.local** — No esta trackeado por git
5. **Nunca rm -rf** — Siempre `git worktree remove`
6. **Merge secuencial** — Un branch a la vez en master, resolver conflictos antes del siguiente
7. **Max 3-4 worktrees** — Por limites de disco y file watchers de macOS

## 8.4 Comandos Practicos

```bash
# Crear directorio de worktrees
mkdir -p /Users/lr0y/POD-AI-PDR/.worktrees

# Crear worktree para frontend production
git worktree add -b feat/frontend-prod \
  /Users/lr0y/POD-AI-PDR/.worktrees/feat-frontend-prod master

# Copiar env
cp project/frontend/.env.local \
  /Users/lr0y/POD-AI-PDR/.worktrees/feat-frontend-prod/project/frontend/.env.local

# Instalar deps
cd /Users/lr0y/POD-AI-PDR/.worktrees/feat-frontend-prod/project/frontend && npm ci

# Lanzar Claude Code en ese worktree
claude --project-dir /Users/lr0y/POD-AI-PDR/.worktrees/feat-frontend-prod

# Cuando termine, limpiar
git worktree remove /Users/lr0y/POD-AI-PDR/.worktrees/feat-frontend-prod
git branch -d feat/frontend-prod
git worktree prune
```

## 8.5 Optimizacion de Disco

| Estrategia | Ahorro | Complejidad |
|-----------|--------|-------------|
| Aceptar duplicacion (npm ci cada uno) | 0% | Nula |
| Usar **pnpm** (store compartido) | ~70% | Baja |
| Solo instalar lo necesario (skip frontend si solo backend) | ~90% | Media |
| Symlink node_modules | NO RECOMENDADO | — |

**Recomendacion**: Migrar a pnpm a medio plazo. Por ahora, aceptar duplicacion con max 3 worktrees.
