**Implementation**:

- If all results are below threshold, add fallback message and flag
- Response includes `lowRelevance: true` and user-friendly message
- Relevant queries return normal response without flags

**Code Logic**:
```typescript
const SIMILARITY_THRESHOLD = 0.65
const hasRelevantResults = searchResults.some(r => r.similarity >= SIMILARITY_THRESHOLD)

if (!hasRelevantResults) {
  response.message = "No highly relevant results found. Showing best matches..."
  response.lowRelevance = true
}
```
