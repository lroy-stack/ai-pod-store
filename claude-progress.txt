### Feature #101: Shipping estimate in cart works ✅

**Implementation**:
- Created `shipping_zones` table in Supabase with columns: country_code, zip_pattern (SQL LIKE patterns), state_code, base_rate, per_item_rate, free_shipping_threshold, estimated_days_min, estimated_days_max, active
- Inserted sample shipping zones for US (standard, NYC, CA, IL, AK, HI) and international (CA, GB, DE, FR, ES, IT, AU, JP)
- Created POST `/api/cart/shipping-estimate` endpoint that:
  - Accepts zipCode, countryCode, cartTotal, itemCount
  - Matches zip code against zone patterns (specific patterns prioritized over wildcards)
  - Calculates shipping cost: base_rate + (per_item_rate × (itemCount - 1))
  - Returns free shipping if cartTotal >= free_shipping_threshold
  - Returns estimated delivery days range
- Added shipping estimate UI to CartView:
  - ZIP code input field with "Calculate" button
  - Shipping estimate box displaying: cost (or "FREE"), delivery days, free shipping threshold message
  - Order summary updated to show shipping cost or "FREE" instead of "Calculated at checkout"
  - Final total includes shipping cost
- Translation keys added for EN/ES/DE: shippingEstimate, zipCodePlaceholder, zipCodeRequired, calculate, calculating, shippingCost, freeShipping, free, estimatedDelivery, freeShippingThreshold, shippingCalculated, shippingCalculationFailed

**Verification**:
1. **Free shipping test (NYC, cart $2474.01)**:
   - Entered ZIP code "10001" in cart
   - Clicked "Calculate" button
   - ✅ Shipping estimate displayed: "Free Shipping" / "FREE"
   - ✅ Estimated delivery: "2-4 business days"
   - ✅ Toast notification: "Shipping estimate updated"
   - ✅ Order summary shows "FREE" for shipping
   - ✅ Total remains $2474.01 (no shipping added)

2. **Paid shipping test (standard US, cart $30, 2 items)**:
   - API test: `curl POST /api/cart/shipping-estimate -d '{"zipCode":"75001","cartTotal":30,"itemCount":2}'`
   - ✅ Response: `{"cost":7.49,"isFree":false,"freeShippingThreshold":50,"estimatedDaysMin":5,"estimatedDaysMax":7}`
   - ✅ Calculation correct: $5.99 base + ($1.50 × 1 extra item) = $7.49
   - ✅ Free shipping threshold shown: "Add $20 more for free shipping"

3. **Alaska test (remote zone, cart $30, 1 item)**:
   - API test: `curl POST /api/cart/shipping-estimate -d '{"zipCode":"99501","cartTotal":30,"itemCount":1}'`
   - ✅ Response: `{"cost":12.99,"isFree":false,"freeShippingThreshold":100,"estimatedDaysMin":7,"estimatedDaysMax":14}`
   - ✅ Higher rate for remote zone ($12.99 vs $5.99 standard)
   - ✅ Longer delivery window (7-14 days vs 5-7 days)
