### Critical Security Issues Identified in Spec
1. Admin: /api/admin/setup-rbac is PUBLIC (creates admin accounts!)
2. Admin: Cookie is unsigned JSON (trivially forgeable)
3. Admin: 66/69 API routes without requireAuth()
4. Admin: middleware.ts excludes ALL /api/* routes
5. MCP: JWT decode without signature verification (session.ts:68-92)
6. Printify: HMAC uses === instead of timingSafeEqual()
7. Database: 25+ tables without RLS, USING(true) on messaging
8. Frontend: Telegram webhook has fallback secret
9. Frontend: ThemeLoader uses dangerouslySetInnerHTML for CSS
