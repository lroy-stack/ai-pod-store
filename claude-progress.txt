### Target: Feature #142 - Product search tool produces product grid artifact

### Investigation Results:

**ROOT CAUSE IDENTIFIED**: AI SDK 6 (v6.0.86) + Google Gemini has a **known incompatibility** with function calling schema validation.

Error: `Unable to submit request because 'product_search' functionDeclaration parameters schema should be of type OBJECT`

**Attempts made**:
1. ❌ `z.object({...})` — Direct Zod schema (original approach)
2. ❌ `jsonSchema({ type: 'object', properties: {...} })` — Manual JSON Schema
3. ❌ Simplified schema with single required string field
4. ❌ Removed `.default()` and `.optional()` modifiers
5. ❌ Attempted OpenAI provider (package not installed)

**All attempts failed with identical error.** The AI SDK is not correctly converting Zod/JSON schemas to Google Gemini's expected Function Calling format.

### Evidence:
- Basic chat (without tools) works perfectly with Gemini
- Tool execution fails immediately at schema validation (before execute() is called)
- Same schema structure works with OpenAI provider in AI SDK docs
- This is a provider-specific schema translation bug in `@ai-sdk/google@3.0.29`
