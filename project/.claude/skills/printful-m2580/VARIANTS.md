## Comparison: M2580 vs MC1087

| Property | M2580 (PREMIUM Hoodie) | MC1087 (PREMIUM Tee) |
|---|---|---|
| Catalog ID | 380 | 917 |
| Product type | Pullover Hoodie | T-Shirt |
| Total colors | 23 | 5 |
| Core dark colors | 2 (Black, Navy Blazer) | 3 (Black, Navy Blazer, Vintage Black) |
| Extended dark | 7 additional | 0 (only 5 colors total) |
| Sizes | S-3XL (6) | S-4XL (7) |
| Front canvas | **1800x1800** (square) | 1800x2400 (portrait) |
| Sleeve canvas | **450x1800** (vertical) | 600x525 (landscape) |
| `label_inside` | Yes, 750x750 / 300 DPI (+$0.99) | Yes, 450x450 / 150 DPI (+$0.99) |
| `embroidery_wrist` | Yes (left + right) | No |
| Base cost S-XL | $22.55 | $14.75 |
| Material | 100% cotton face / 65% cotton 35% poly, 8.5 oz | 100% combed ring-spun cotton, 6.5 oz |
| Fit | Classic streetwear, kangaroo pocket | Boxy / structured |
| Sizing | Runs small | Standard |
| UK region | No | No |

**CRITICAL:** MC1087 sleeve branding files (600x525) are **incompatible** with M2580 sleeves (450x1800). New vertical branding assets must be rendered and uploaded.
