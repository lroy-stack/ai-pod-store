### Performance Concerns
- **Google Fonts**: Loaded as render-blocking `<link rel="stylesheet">`. Should use `next/font` for self-hosting (Inter is already imported via `next/font/google` but the theme system adds a second fonts URL dynamically).
- **Dual font loading**: `Inter` loaded via `next/font/google` AND via Google Fonts stylesheet URL. Redundant; wastes bandwidth.
- **Service Worker (Serwist)**: Good for repeat visits but adds JS overhead on first load.

## Critical Gaps

### 1. SITEMAP DOES NOT INCLUDE PRODUCTS (Severity: CRITICAL)
**File**: `/frontend/src/app/sitemap.ts`

The sitemap only lists 6 static URLs (3 homepages + 3 chat pages) and references 3 locale sub-sitemaps (`sitemap-en.xml`, `sitemap-es.xml`, `sitemap-de.xml`) that **do not exist**. No product, category, or blog URLs are included.

**Impact**: Google cannot discover products via sitemap. Products are only discoverable through crawling internal links, which is significantly slower and less reliable for large catalogs.

**Fix**: Rewrite `sitemap.ts` to be `async` and query Supabase for all active products, categories, and blog posts. Generate entries per locale with `lastmod` from `updated_at`.

### 2. PRODUCT URLs USE UUIDs INSTEAD OF SEMANTIC SLUGS (Severity: HIGH)
**File**: `/frontend/src/app/[locale]/(app)/shop/[id]/page.tsx`

Product URLs are `/en/shop/547be69f-1234-...` instead of `/en/shop/shadow-tee`. The route param is `[id]` (UUID).

**Impact**: UUID URLs have zero keyword value, are not user-friendly, and hurt CTR in SERPs. Semantic slugs contribute to ranking for product-name keywords.

**Fix**: Add a `slug` column to the `products` table (generated from title, unique). Create a `[slug]` route that resolves slug to ID. Redirect old UUID URLs with 301.

### 3. CATEGORY PAGE DESCRIPTIONS NOT LOCALIZED (Severity: MEDIUM)
**File**: `/frontend/src/app/[locale]/(app)/shop/category/[slug]/page.tsx` (line 112)

Category meta descriptions are hardcoded in English: `"Browse our collection of ${categoryName} products..."`. This affects es/de rankings.

### 4. BLOG PAGES MISSING hreflang AND CANONICAL (Severity: MEDIUM)
**File**: `/frontend/src/app/[locale]/(app)/blog/[slug]/page.tsx`

Blog `generateMetadata` does not set `alternates.canonical` or `alternates.languages`. Multi-language blog posts will compete with each other in SERPs and may be treated as duplicate content.

### 5. SITEMAP INCLUDES CHAT PAGES (Severity: LOW)
Chat pages (`/en/chat`, `/es/chat`, `/de/chat`) are in the sitemap with priority 0.9. These are interactive app pages with no static content value for SEO. They waste crawl budget.

### 6. JSON-LD URLs INCONSISTENT IN SHOP/CATEGORY PAGES (Severity: LOW)
**Files**: Shop page (line 409, 425) and Category page (line 308, 318)

ItemList product URLs use `/products/${id}` but the actual route is `/shop/${id}`. This mismatch means Google sees broken structured data URLs.

```
WRONG:  ${baseUrl}/${locale}/products/${product.id}
RIGHT:  ${baseUrl}/${locale}/shop/${product.id}
```

### 7. NO `<link rel="icon">` IN LAYOUT (Severity: LOW)
Favicon exists at `/favicon.ico` (auto-served by Next.js) and sized versions in `/brand/`, but no `<link rel="icon" sizes="32x32">` or `<link rel="icon" sizes="16x16">` declared. Some browsers/crawlers may not discover sized favicons.

## Recommendations (Prioritized by Organic Traffic Impact)

### P0 -- Critical (Do within 1 week)

1. **Rewrite sitemap to be dynamic** -- Query all active products, categories, and blog posts from Supabase. Generate per-locale entries with proper `lastmod`. Remove references to non-existent sub-sitemaps. Estimated traffic impact: **+30-50% crawl coverage**.

2. **Fix JSON-LD URL mismatch** (`/products/` vs `/shop/`) -- Change all ItemList product URLs from `/products/${id}` to `/shop/${id}` in shop page and category page. Prevents Google from reporting structured data errors. Estimated fix time: 5 minutes.

### P1 -- High (Do within 1 month)

3. **Add semantic slug URLs for products** -- Add `slug` column to products table, generate from title. Create `/shop/[slug]` route. 301-redirect `/shop/[uuid]` to `/shop/[slug]`. Estimated traffic impact: **+10-20% CTR from SERPs**.

4. **Localize category page meta descriptions** -- Use `next-intl` translations instead of hardcoded English strings. Affects rankings in es/de markets.

5. **Add hreflang + canonical to blog pages** -- Add `alternates` to blog `generateMetadata`. Prevents duplicate content penalties across locales.

### P2 -- Medium (Do within 2 months)

6. **Product descriptions should be localized** -- Currently single-language. Store `description_en`, `description_es`, `description_de` or use translation API. Major impact for non-English organic traffic.

7. **Fix empty alt text on category preview thumbnails** -- `CategoryCard.tsx:74` has `alt=""`. Use category name or product title.

8. **Use `next/image` for blog featured images** -- Replace raw `<img>` with `next/image` for automatic optimization.

9. **Remove chat pages from sitemap** -- They have no SEO value and waste crawl budget.

10. **Add favicon `<link>` tags** -- Declare sized favicons in layout for consistent brand display in SERPs.

### P3 -- Low (Backlog)

11. **Eliminate dual font loading** -- Either use `next/font/google` (already imported) OR the dynamic Google Fonts URL, not both. Saves ~50-100KB on initial load.

12. **Add `Organization.sameAs`** -- Populate social media URLs in the landing page Organization schema when social accounts exist.

13. **Add review snippets to JSON-LD** -- Individual `Review` objects (not just AggregateRating) for rich snippet eligibility in SERPs.

14. **Consider product schema `brand` field** -- Add `"brand": { "@type": "Brand", "name": "SKAPARA" }` to product JSON-LD.

15. **Add `ItemList` structured data to sitemap for Google Merchant Center** -- Helps with free product listings in Google Shopping.
