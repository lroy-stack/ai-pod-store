## NOTAS TECNICAS PARA CREACION

1. **GPSR obligatorio**: Cada producto necesita safety_information, manufacturer (Textildruck Europa / Printful), material, care_instructions
2. **product_details JSONB**: Todos los campos GPSR + print_technique (DTG/embroidery/sublimation/UV) + brand (SKAPARA)
3. **Categorias en Supabase**: Usar slug correcto de la tabla categories + category_id UUID
4. **Traducciones**: `translations` JSONB con claves `es` y `de` para name + description
5. **Variantes**: Filtrar solo variantes EU disponibles del BP/Provider
6. **Imagenes**: Sync post-publish, front-first ordering, Set guard para variant image_url
7. **Precios en Printify PRIMERO**: El cron sync margin fixer sobreescribe si margen <35%
8. **Regex parseVariantTitle**: Usar version corregida con `$` anchor
9. **Disenos SVG→PNG**: Renderizar a canvas size del BP correspondiente (ej: BP6=4606x5787, BP77=3531x2908)
