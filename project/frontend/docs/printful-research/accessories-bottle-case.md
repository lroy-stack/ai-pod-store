> All prices are USD. EUR base costs will differ — verify in dashboard.

### EU Fulfillment
- **Status: YES — EU-fulfilled from Latvia (Riga).**
- Printful's Latvia fulfillment center (near Riga International Airport) handles phone cases among other accessories.
- EU fulfillment means: no customs duties for EU customers, faster delivery (2–5 business days within EU), and no import VAT complexity.
- Printful's facilities in Latvia, Spain (Barcelona), and UK (Birmingham) all serve EU orders.
- Phone cases are in-house printed products at Printful (not outsourced), making EU fulfillment reliable.

### Print Technique & Areas
- **Snap Case:** Sublimation printing (heat press transfer). Confirmed by Fourthwall (Printful-powered storefront) product label "snap-case-for-iphone-sublimation".
- **Tough Case:** Sublimation printing (heat press transfer). Confirmed in Printful's design guide (German version): *"Snapcase/Hardcase: Sublimation printing via heat press transfer."*
- **Clear Case:** UV printing. Confirmed by Printful's design guide: *"Transparent cases: UV printing with Mimaki Inkjet and Inkcups Helix printers."* A white underbase and colored top coat are printed simultaneously.
- **MagSafe Tough Case:** UV printing (the design sits on the polycarbonate back panel; the MagSafe ring is embedded, not printed).
- **MagSafe Clear Case:** UV printing.

**Print Area (applies to all case types):**
- **Physical dimensions:** 7.4 cm × 15.5 cm (2.93" × 6.10") — back panel only.
- **DPI:** 300 DPI minimum (required for all phone cases).
- **Pixel dimensions at 300 DPI:** ~879 × 1,830 px (2.93" × 6.10" × 300 DPI).
- **Print placement:** Back of the case only. Sides/edges are NOT printed — edges stay clean/unprinted.
- **Camera cutout:** Account for the camera hole position in your design — keep important elements away from the camera area.
- **One template fits all models:** Printful uses one print file scaled proportionally for all iPhone models (per older documentation; verify this still applies to iPhone 16/17 Pro Max dimensions).

### Design Requirements
- **DPI:** 300 DPI (mandatory for phone cases — smaller product size demands higher resolution).
- **File Formats:** PNG (recommended, supports transparent backgrounds) or JPEG. PSD also accepted.
- **Color Profile:** sRGB IEC61966-2.1.
- **Pixel Dimensions:** ~879 × 1,830 px at 300 DPI (derived from 2.93" × 6.10" physical print area).
- **Transparency rules (especially for Clear Case / UV-printed cases):**
  - Keep design elements at **0% or 100% opacity** — avoid semi-transparent areas; they cause patchy/uneven UV ink adhesion.
  - For sublimation (Snap/Tough): gradients and transparency work well.
- **Safe Zone:** Keep critical text and faces ~3–5 mm inside each edge; do not place important elements near the camera cutout.
- **Bleed:** Extend artwork 2–3 mm beyond the visible print boundary to prevent white gaps from minor alignment shifts.
- **Remove template guides:** Export final file without the guide/safe-zone overlay layers.

### Case Types & Materials

| Case Type | Material | Protection Level | Finish Options | Notes |
|---|---|---|---|---|
| Snap Case | 100% Polycarbonate (PC) | Light (scratch protection) | Matte or Gloss | Wireless charging compatible; slim profile |
| Tough Case | PC shell + TPU inner lining | Medium-high (drop resistant) | Matte or Gloss | Dual-layer; button covers included; ports/switches have cutouts |
| Clear Case | Flexible TPU / PC hybrid | Light (scratch + minor drops) | Matte (smooth finish) | Transparent background shows phone color; UV print on back |
| MagSafe Tough Case | PC shell + TPU inner lining | Medium-high | Matte or Gloss | MagSafe ring embedded in back; compatible with MagSafe accessories |
| MagSafe Clear Case | Flexible TPU / PC hybrid | Light | Matte | Transparent + MagSafe ring; UV print on back |

**Notes on materials:**
- Snap Case: PC only — lightweight, minimal bulk, less protective than dual-layer.
- Tough Case: PC outer + TPU inner — the TPU absorbs shock; PC provides rigid outer structure.
- Clear Case: TPU/PC hybrid — flexible enough to snap on/off; transparent to show phone body color.
- All cases: wireless charging compatible, precisely aligned port openings, button covers (switches/ports have cutouts not covers).

## API Notes

### Printful Catalog API — Phone Cases

```
GET https://api.printful.com/v2/catalog-products?category_id=...
```

Known catalog IDs (from research):
- Snap Case for iPhone: **683**
- MagSafe Tough Case: **798**
- Tough Case, Clear Case, MagSafe Clear Case: IDs not confirmed via public sources — retrieve via API or dashboard.

To get print files / placement specs programmatically:
```
GET https://api.printful.com/v2/catalog-products/{id}
GET https://api.printful.com/v2/catalog-products/{id}/sizes  (variant/size list)
```

### Printful Catalog API — CamelBak Thrive

- **Catalog ID:** Not publicly available. Retrieve via:
```
GET https://api.printful.com/v2/catalog-products?search=camelbak+thrive
```
Or browse drinkware category in the Printful dashboard.

### Design Templates (API)

Each catalog product exposes print file templates via:
```
GET https://api.printful.com/v2/catalog-products/{id}/print-files
```
This returns pixel dimensions, DPI, and placement boundaries for all print positions — the authoritative source for production-ready specs.

### EU-Specific Pricing

Printful v2 API returns EUR pricing when the store currency is EUR:
```
GET https://api.printful.com/v2/catalog-products/{id}/prices
```
Returns per-variant base costs in the store's configured currency.
