## DTFlex/DTFilm Technical Notes

DTFlex (marketed name) = DTFilm (API technique key: `dtfilm`)

- Printful's premium DTF (Direct-to-Film) technique
- Design printed to PET film → adhesive powder → heat-cured → heat-pressed at 165°C → cold peel
- **Advantages over embroidery**: Full CMYK color, gradients, photographic content, fine details, larger print area
- **Advantages over embroidery on hats**: 5.00"×2.00" vs 4.00"×1.75" (embroidery standard front)
- **Currently available on**: Otto Cap 104-1018 (CAT=396), Beechfield B682 (CAT=532)
- **Canvas**: PF#816 = 1500×600px @300dpi (consistent across products)
- **Print price**: +2.60€ per placement (vs +2.95€ for embroidery)
- **Limitation**: Front-only placement (no back/side in DTFilm mode)

## DTFlex / DTFilm — Complete Technical Reference

> **DTFlex** es la técnica de impresión directa a film (DTF) premium de Printful, perfeccionada durante más de una década de pruebas, ofrecida exclusivamente a través de Printful. A diferencia de la DTF tradicional, DTFlex ha sido diseñada específicamente para la producción bajo demanda.

### API Key: `dtfilm` (marketing name: DTFlex)

### Process
1. Design printed to PET film (CMYK + white underbase)
2. Adhesive powder applied
3. Heat-cured
4. Heat-pressed onto fabric at 165°C
5. Cold peel — produces clean edges without glue halo

### Capabilities
- **Full CMYK color** — unlimited colors, gradients, photographic content
- **Fine detail** — thin lines, small text possible (unlike embroidery)
- **No color matching needed** — unlike embroidery's 15-thread palette
- **Larger print area on hats**: 5.00"×2.00" (PF#816) vs embroidery 4.00"×1.75" (PF#78)

- **Works on polyester** (sports jerseys, windbreakers) where DTG fails
